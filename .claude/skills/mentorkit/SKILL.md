# MentorKit ODD

The canonical contract is `AGENTS.md`.

Use this skill when the task requires MentorKit's engineering workflow:
1. Determine authorization.
2. Explore relevant context.
3. Resolve material uncertainty.
4. Classify SMALL or SUBSTANTIAL.
5. For SUBSTANTIAL work, maintain `odd/tasks/<feature>.md`.
6. Implement only the authorized scope.
7. Verify before completion.
8. Commit reviewable work units when appropriate.
9. Close with status, verification, and risks.

Do not duplicate or redefine ODD semantics in Claude-specific instructions.
