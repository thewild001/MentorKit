# MentorKit ODD

The canonical contract is `AGENTS.md`.

Use ODD proportionally:
AUTHORIZE → EXPLORE → UNCERTAINTY → CLASSIFY → TRACK → IMPLEMENT → VERIFY → COMMIT → CLOSE.

For SUBSTANTIAL work, persist the durable feature document in `odd/tasks/<feature>.md`. Do not expand scope without authorization and verify before claiming completion.
